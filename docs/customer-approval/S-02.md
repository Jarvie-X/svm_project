# S-02 customer approval — audience and result language

**Approval status:** Pending customer confirmation  
**Approval target date:** 2026-09-08

## Proposed audience

The primary audience is learners being introduced to classification with a
small demonstration. Reviewers and product stakeholders are secondary
audiences. The experience should make clear that this is an educational
demonstration, not a production wine decision system.

## Proposed displayed language

### Title

**Wine sample classification demonstration**

### Categories

**Class 0**, **Class 1**, and **Class 2** — the three recognized categories in
the approved Wine Recognition dataset. These are dataset target labels; they
are not wine varietals, quality grades, or recommendations.

### Individual result

- **Predicted category:** Class `<n>`
- **Prediction confidence:** `<percent>%`

Confidence must not be presented as a guarantee. If the experience displays a
summary metric, use **Held-out test accuracy** and show the evaluation method
and test sample count beside the percentage.

### Measurement guidance

Each sample is represented by **13 chemical measurements**. Display the
measurement names and units from the approved dataset metadata where
available. This guidance describes the dataset; it does not instruct learners
to collect measurements without suitable laboratory equipment.

### Accuracy and safety context

Accuracy summarizes performance across labeled test samples. It does not
guarantee an individual prediction. Results must not be described as wine
quality, safety, health, or purchasing advice.
