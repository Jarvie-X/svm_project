# S-01 — Confirm classification runtime readiness

## Objective

Provide a repeatable, executable Iris-classification workflow that proves the
deployment runtime can load the built-in dataset, train an SVM classifier, and
evaluate it without errors.

## Technical approach

- Use scikit-learn's built-in `load_iris()` dataset; no network or checked-in
  dataset artifact is required.
- Split features and labels with `train_test_split` using a fixed
  `random_state`, stratification, and an explicit test size.
- Train `sklearn.svm.SVC` on the training partition and evaluate predictions
  on the held-out partition with accuracy.
- Expose the workflow as a small Python API and a command-line entry point so
  the same operation can be run locally or as a deployment readiness check.
- Declare the runtime dependency in `pyproject.toml` and provide a test that
  exercises the complete workflow.

## Result contract

The workflow returns dataset and split sizes, the trained classifier, and the
evaluation accuracy. It raises an error if the runtime cannot load the
dataset, train the classifier, or produce evaluation predictions.

## Verification

Run:

```text
python -m svm_project.classifier
pytest
```

The command must report successful dataset loading, training, and evaluation;
the test must verify the fixed split and a valid accuracy result.
