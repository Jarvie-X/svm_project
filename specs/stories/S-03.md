# S-03 — Deliver Wine Recognition classification

## Technical implementation specification

### Objective

Provide a non-interactive, repeatable SVM workflow that trains on the approved
scikit-learn Wine Recognition dataset using all thirteen measurements and
reports held-out performance for its three target categories.

### Implementation

- Add `wine_classifier.py` with a callable workflow and a command-line entry
  point.
- Load the dataset with `sklearn.datasets.load_wine`, using the complete
  feature matrix rather than selecting a subset of measurements.
- Split examples into training and evaluation sets with
  `train_test_split(test_size=0.25, random_state=42, stratify=target)`.
  The explicit seed and stratification make the membership and class balance
  repeatable across runs.
- Train an SVM in a `Pipeline` with `StandardScaler` followed by `SVC`, so
  feature scaling is learned only from training examples. Use the default
  RBF SVC configuration and evaluate only on the held-out examples.
- Return structured evidence containing dataset dimensions, train/evaluation
  counts, the evaluation indices, and accuracy. The CLI prints these values
  and exits successfully only when accuracy is at least 90%.
- Keep the workflow fully automatic: one command loads data, trains, evaluates,
  and reports the result without prompts or external files.

### Verification

Run the complete test suite and run the classifier CLI repeatedly:

```text
python -m pytest
python -m wine_classifier
python -m wine_classifier
```

Confirm that both runs report the same train/evaluation membership and
accuracy, and that held-out accuracy is at least 90%. Record the results in
`docs/verification/S-03.md`.
