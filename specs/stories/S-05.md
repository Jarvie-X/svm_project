# S-05 — Explain accuracy and prediction

## Technical implementation specification

### Objective

Extend the guided Wine Recognition prediction result so a non-technical
learner can see how the classifier was evaluated, what measurements were
submitted, which approved dataset category was predicted, and what that
category means in context.

### Implementation

- Enrich the structured prediction result with the supplied measurements and
  the deterministic held-out evaluation evidence from S-03.
- Keep the approved category wording exactly as `Class 0`, `Class 1`, or
  `Class 2`; do not present these dataset target labels as wine varietals or
  quality grades.
- After a successful prediction, print every submitted measurement in model
  order, the label `Held-out test accuracy`, the held-out sample count and
  fixed evaluation method, and the predicted category.
- Include plain-language guidance that the category is an educational Wine
  Recognition dataset label, that accuracy summarizes labeled test samples
  rather than guaranteeing an individual prediction, and that the output is
  not wine quality, safety, health, or purchasing advice.
- Preserve S-04 validation behavior and the non-zero error result for invalid
  input. Add automated tests for all four acceptance criteria and for the
  structured result's evidence.

### Verification

Run:

```text
python -m pytest -q
python -m wine_prediction --values <13 valid values>
```

Review the successful command output and confirm that the accuracy, complete
input summary, approved predicted category, and category guidance are all
visible after prediction. Record command results in
`docs/verification/S-05.md`.
